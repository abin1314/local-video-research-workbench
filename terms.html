Terms of use

A private editorial research workflow, with separate checks for platform permission and source rights.

Published 26 October 2026 · Contact: fearthegod77@gmail.com

1. Application and documentation

Local Video Research Workbench is used by its owner for local source discovery and manual review. The public website is provided as an informational entry point, not a hosted API service or a public video library. Access to the local tool is not sold.

2. YouTube terms

The application uses YouTube API Services. By using the API client, users agree to be bound by the YouTube Terms of Service. Use must also comply with the YouTube API Services Terms of Service and Developer Policies.

3. Research and source rights

API results and licence fields are research leads. They do not verify that an uploader owns a video, grant permission for every possible use, or clear rights in people, music, brands or third-party material. The owner must evaluate the original source and relevant permissions before reusing any material.

These terms do not grant permission from YouTube to download or store audiovisual content. A separate copyright licence is not represented as YouTube’s prior written approval under the API policies.

4. Scope review required

The owner has confirmed that selected YouTube videos are downloaded through a separate media-fetching script. No prior written approval from YouTube for that behaviour has been supplied in this preparation. The owner must resolve the required permission or actual restrictions on the submitted client before claiming compliance. Publishing policy text does not itself disable or change the code.

This documentation does not certify that the whole toolkit is compliant. No shared tool or Claude instruction has been changed as part of the website preparation.

5. Data and privacy

The privacy policy describes the current data flow and storage behaviour. The owner has confirmed a manual 30-day retention and deletion commitment; an automatic maintenance task is planned but not yet active. Policy access and any required acceptance also need to be reflected in the real client.

6. Availability and contact

Source availability, API responses and licence indicators can change. Research results require human review and should not be treated as complete or permanently current. Questions about the application or these terms can be sent to fearthegod77@gmail.com.

These terms introduce no subscription, payment obligation, transfer of ownership of user content or assertion of affiliation with the platforms mentioned.
