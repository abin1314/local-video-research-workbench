Privacy policy

What the local workflow accesses, where information goes, and what still needs an operating decision.

Published 26 October 2026 · Contact: fearthegod77@gmail.com

1. Scope and operator

Local Video Research Workbench is an owner-operated research workflow associated with the @SvinthZabik channel. It uses YouTube API Services. This policy distinguishes the public documentation website from the local application and its production records.

2. Information handled

InformationPurpose and location
Search keywords and topic categoriesUsed to request relevant public videos. The search request is sent to Google/YouTube.
Public video IDs, URLs, titles, descriptions, channel names, thumbnail URLs, duration, definition and licence indicatorsUsed for candidate discovery, source tracing and manual review. API responses and selected fields are stored in local cache and project outputs.
Local research notes and decisionsUsed by the owner to evaluate candidates. These are the owner’s editorial records, not YouTube-generated assessments.
API key and network informationThe key is read from local configuration and supplied to Google for API authentication. Google also receives the request’s normal network information. The key is not included in this website.

The inspected research component does not request YouTube account passwords or OAuth access tokens. No public account system or payment service is offered.

3. Processing and sharing

  • Google / YouTube: processes API requests and serves linked YouTube pages or thumbnails. See the Google Privacy Policy.
  • Claude / Anthropic: when the owner supplies prompts, files or tool results to Claude, that supplied information can be processed by Anthropic. The local workflow is not described as keeping all information exclusively on the device. See Anthropic’s privacy policy; actual handling depends on the product and account settings used.
  • GitHub Pages: the public documentation host can log visitor IP addresses for security. These pages themselves contain no analytics scripts, tracking pixels, account forms or application uploads. See the GitHub Privacy Statement.
  • Other websites: following an external source link opens the destination’s services and policies.

No local project datasets, account credentials or production files are intended for publication in the documentation repository.

4. Current storage behaviour

VERIFIED IN SOURCE · 26 October 2026

The shared HTTP helper can reuse a cached response for up to three days. An expired response is fetched again when that same request is made. This reuse period is not automatic deletion of every cached file.

Search outputs include local JSON records and a Markdown research log. The inspected code does not enforce scheduled deletion or refresh of all historical exports and copies. These pages do not claim that an automated 30-day lifecycle is already implemented.

5. Retention and deletion commitment

Manual commitment confirmed by the owner on 26 October 2026. YouTube API data controlled by the owner is to be refreshed or deleted within 30 days, including cached responses, exports and copied API metadata. This commitment requires an actual manual operating process; the shared code does not implement it automatically. A separate maintenance task has now been configured for every 28 days at 09:00 Asia/Taipei. Its first maintenance run has not yet completed; configuration alone is not evidence that all stored data or copies meet the retention commitment.

Any deletion request would be reviewed through the contact address, with applicable stored user data removed promptly and within the YouTube-required period. Requests about data on YouTube itself must be directed to YouTube; removing a local record does not remove a video or channel.

Implementation and the handling of copies supplied to external services must be checked before making a final compliance declaration. The schedule was configured after form preparation, as requested by the owner. A read-only initial inventory identified YouTube API cache files; no cache, export or production file was deleted or refreshed in that inventory. No existing project data has been deleted or changed to prepare these pages.

6. Contact and changes

Send privacy questions or requests identifying the relevant public video or local data category to fearthegod77@gmail.com. Do not send passwords, API keys or identity documents.

Any material change in collection, sharing or retention must be reflected in a revised policy. This policy describes the current workflow and the owner’s confirmed retention commitment. Download-related permissions remain subject to separate review.
