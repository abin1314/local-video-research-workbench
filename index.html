A private local Python workflow supporting documentary and educational video research on archaeology, aviation, engineering and nature.

Owner-operated project · @SvinthZabik on YouTube · No public user accounts

01 / DISCOVER

Search public metadata

Use search.list to find topic-specific videos and videos.list to check details and licence indicators.

02 / TRACE

Identify original sources

Keep source links, channel names and candidate records. A Creative Commons label is a lead for review.

03 / REVIEW

Make human decisions

The owner checks relevance, original publishers and reuse rights before choosing material for a production.

How the research component works

Owner / Claude→Local Python script↔YouTube Data API→Local records + human review

Architecture illustration, not an application screenshot.

The research component reads public video metadata using a locally stored API key. It does not use Google OAuth sign-in or make channel-management changes through these two API methods. When the owner supplies research material to Claude, that material is also subject to Anthropic’s processing and the owner’s chosen settings.

ABOUT THIS WEBSITE

A documentation entry point

The application runs on the owner’s computer. This static website explains its purpose and proposed policies; it does not run the Python workflow, expose the API key or offer a public search box.

Review of the actual application requires screenshots or a demonstration of the real local workflow. The pages here do not substitute for that evidence.

Wider-toolkit scope still needs review

The owner also uses a separate media-fetching command to download selected YouTube videos. This website does not claim that the entire production workflow is metadata-only or that required platform permissions have already been obtained.
